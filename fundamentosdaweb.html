Fundamentos da Web

Página Estática

Uma página estática apresenta conteúdo que permanece igual quando é acessado novamente.

Um exemplo é uma página institucional de uma empresa,contendo informações sobre a empresa e seus serviços.

Página Dinâmica

Uma página dinâmica pode ter seu conteúdo processado e alterado de acordo com informações recebidas pelo sistema.

Exemplo real pode ser uma loja virtual ou portal de noticias de que apresentam conteúdos que são modificados diariamente, seja pela logica de vendas ou por novas noticias diárias.

Caminho básico entre navegador, servidor e resposta

  1. Usuário acessa uma página pelo navegador.
  2. Navegador envia uma requisição para o servidor.
  3. Srvidor recebe a requisição.
  4. Servidor processa a requisição.
  5. Servidor envia uma resposta para o navegador.
  6. Navegador apresenta o resultado para o usuário.
